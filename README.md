# Практична робота: Черга (Queue)

Вісім задач на Python за умовою практичної роботи. Кожна задача знаходиться в окремому `.py` файлі. Усі приклади виконуються без сторонніх бібліотек: застосовується тільки стандартний Python.

## Завдання

| Файл | Задача | Основна ідея | Часова складність |
|---|---|---|---|
| `01_first_unique_character.py` | Перший унікальний символ | Підрахунок частот | O(n) |
| `02_stack_using_queues.py` | Стек за допомогою черги | Перестановка після push | push O(n), pop O(1) |
| `03_recent_counter.py` | Кількість останніх викликів | Черга часових міток | O(1) амортизовано на ping |
| `04_circular_queue.py` | Циклічна черга | Масив, head, count | O(1) на операцію |
| `05_circular_deque.py` | Циклічна двобічна черга | Масив із кільцевою індексацією | O(1) на операцію |
| `06_stamping_sequence.py` | Штампування послідовності | Зворотне стирання через чергу | O(nm) |
| `07_sliding_window_maximum.py` | Максимум ковзного вікна | Монотонний дек | O(n) |
| `08_constrained_subsequence_sum.py` | Обмежена сума підпослідовності | Динамічне програмування + дек | O(n) |

**Примітка щодо нумерації:** в оригінальних знімках дві задачі мають номер 3; тут для зручності всі **вісім різних** завдань перенумеровано 1–8. Завдання зі штампування та дві задачі з вікном через це мають інші номери, ніж на окремих знімках.

## Як запустити

1. Встановіть Python 3.9 або новіший.
2. Відкрийте папку в VS Code, запустіть термінал.
3. Виконайте, наприклад:

```bash
python 03_recent_counter.py
python 07_sliding_window_maximum.py
```

У кінці кожного файла є секція `if __name__ == "__main__":` із прикладами. Її можна змінювати, щоб тестувати власні дані.

## Подання

Посилання на цей GitHub-репозиторій вставляється у Google Форму. Методи класів названо відповідно до умов (`enQueue`, `deQueue`, `Front`, `Rear`, `insertFront`, `getRear` тощо).
